# DrikVedic - Vedic Astrology & Panchangam Platform 🪔

A state-of-the-art, full-stack Vedic Astrology, Panchangam & Diagnostic Engine. **DrikVedic** computes high-precision daily Panchangam, evaluates classical Subha Muhurthams with multi-layered dosha validation, analyzes natal horoscopes, assesses longevity (*Ayurdaya*), diagnoses classical Rajayogas and Doshams (with exhaustive cancellation/nullification logic), visualizes South & North Indian charts, and exports HD social share cards and multi-language PDF reports.

Built with **Spring Boot 3 (Java 17)** and **React 18 (Vite 8)**, powered by **Swiss Ephemeris (`swisseph`)** astronomical calculations, and styled with a mobile-first responsive warm saffron aesthetic.

## 🌟 Key Features & Capabilities

### 1. 📅 High-Precision Daily Panchangam & Subha Muhurtham Engine
- **Core Panchangam Limbs**:
  - **Thithi, Nakshatra, Yogam, Karanam**: Exact end-time transition timestamps and next-element previews.
  - **Natural-Language Timing**: Clean grammatical transitions formatted in the active language (e.g. `09:37 AM வரை`, `Until 09:37 AM`, `09:37 AM तक`).
- **Advanced Subha Muhurtham Calculation Engine**:
  - **6-Ghatika Morning Dominance Rule (*Thithi & Nakshatra Viddha*)**: Evaluates the first 6 Ghatikas (2.4 hours / ~08:30 AM) after sunrise to prevent days that start auspicious but transition into inauspicious Thithis/stars early in the morning.
  - **Universal Baseline Prohibitions**:
    - Strictly excludes **Tuesdays** (*Kuja*) and **Saturdays** (*Sani*).
    - Strictly excludes **Rikta Thithis** (4, 9, 14, 19, 24, 29), **Ashtami** (8, 23), **Prathama** (1, 16), and **Amavasya** (30).
    - Strictly excludes **Marana Yogam** and **Prabalarishta Yogam** (requires Amrita or Siddha Yogam).
    - Strictly excludes **Masa Sankranti Days** (Sun ingress into a new zodiac sign between consecutive sunrises).
    - Strictly excludes severe Mahadoshas: **#17 Vyatipata** and **#27 Vaidhriti**.
    - Strictly excludes **Guru Moudhya** (Jupiter combustion $< 11^\circ$ from Sun) and **Sukra Moudhya** (Venus combustion $< 8^\circ$ from Sun).
    - Strictly excludes **Margazhi** (Month 9 / Dhanus).
    - Requires active celestial vitality (**Netram > 0** and **Jeevan > 0.0**).
  - **Time-Bounded Muhurtham Window**: Explicitly calculates usable daytime time slots (e.g. `07:06 AM - 04:17 PM`, `09:37 AM வரை`, `Throughout the day`).
- **Actionable Guidance & Caution Banners (in 6 Languages)**:
  - **Minor Adverse Yogas** (*Vishkambha, Atiganda, Shoola, Ganda, Vyaghata, Vajra, Parigha*): Calculates the exact clock-time window to avoid (first 5 ghatikas / 2 hours after sunrise, e.g. `05:58 AM - 07:58 AM வரை`).
  - **Thithi Soonya (*Dagda Rashi*)**: Checks Moon transit in void signs for the daytime Thithi and flags specific caution for marriage ceremonies.
  - **Seasonal Month Nuances**: Flags Aadi and Purattasi months as auspicious for temple worship and asset purchase while noting traditional marriage exclusions.
  - **Thei Pirai (Krishna Paksha)**: Warns of waning lunar phase with dedicated caution styling.
- **Solar & Lunar Horizons**:
  - Sunrise, Sunset, Moonrise, Moonset using coordinate polygon-based timezone resolution (`timeshape`).
  - Nalla Neram & Gowri Nalla Neram (Day & Night).
  - Rahu Kalam, Yamagandam, Kulikai.
  - Full 24-Hour Planetary Horai Table (12 Day Horais & 12 Night Horais).
  - Abhijit Muhurtham, Vasthu Days & Vasthu Puja timings, and Agni Nakshathiram period detection.
- **Exact Astronomical Chandrastamam**: Computes the exact 8th-house Chandrastamam Janma Nakshatra based on active sunrise Moon longitude using exact distance mathematics (`((N + 12 - 1) % 27) + 1`).

### 3. 🛡️ Classical Dosha Diagnostic & Nullification Engine
Diagnostic scanning for **7 major Doshams** with comprehensive classical nullification rules (*Brihat Parashara Hora Shastra*, *Phaladeepika*, *Deva Keralam*):

1. **Sevvai (Manglik) Dosham**:
   - Scans 1st, 2nd, 4th, 7th, 8th, and 12th houses from Lagna and Moon.
   - **Exemptions & Nullifications**: Mars in own sign (*Aries, Scorpio*) or exaltation (*Capricorn*), conjunct/aspected by Jupiter or Venus, conjunct Moon (*Chandra-Mangala*), Mars in Leo or Cancer, and classical house-sign exemptions (2nd in Gemini/Virgo/Capricorn/Aquarius, 4th in Aries/Scorpio/Cancer, 7th in Cancer/Capricorn/Taurus/Libra, 8th in Sagittarius/Pisces/Gemini/Virgo, 12th in Taurus/Libra/Sagittarius/Pisces).
2. **Kala Sarpa Dosham**: Hemmed planet detection with conjunct/aspect exemptions by Jupiter or Rahu/Ketu in Kendra/Trikona.
3. **Sarpam / Naga Dosham**: Rahu/Ketu in houses 1, 2, 5, 7, 8 with Jupiter Kendra aspect and benefic conjunction nullifications.
4. **Pithru Dosham**: Sun afflicted in 9th house with Jupiter aspect, own sign, or exaltation cancellations.
5. **Putra Dosham**: Malefics in 5th house with Jupiter/benefic aspect and fertile sign exemptions.
6. **Kalathira Dosham**: Malefics in 7th house with Venus strength and benefic aspect cancellations.
7. **Shani Dosham**: Saturn in non-Upachaya houses with Yogakaraka (Taurus/Libra Lagna), own sign, exaltation, and sign exemptions.

### 4. 👑 Classical Rajayoga Engine
Identifies active auspicious Yogas and planetary combinations:

- **Full 4-Rule Parashari Neechabhanga Rajayoga**: Dispositor in Kendra from Lagna/Moon, exaltation lord in Kendra from Lagna/Moon, or direct aspect/conjunction by sign/exaltation lords.
- **Vipareeta Rajayoga**: Lords of Dusthana houses (6th, 8th, 12th) situated exclusively in Dusthana houses (*Harsha*, *Sarala*, *Vimala* Yogas).
- **Dharma-Karmadhipati Yoga**: Conjunction or mutual aspect of 9th lord (Dharma) and 10th lord (Karma).
- **Kendra-Trikona Rajayoga**: Conjunction of a Kendra lord (1, 4, 7, 10) and a Trikona lord (5, 9).
- **Pancha Mahapurusha Yogas**: *Ruchaka* (Mars), *Bhadra* (Mercury), *Hamsa* (Jupiter), *Malavya* (Venus), *Sasa* (Saturn).
- **Solar & Lunar Yogas**: *Gajakesari*, *Budha-Aditya*, *Chandra-Mangala*, *Lakshmi*, *Amala*, *Vesi*, *Vosi*, *Obhayachari*, *Sunapha*, *Anapha*, *Dhurudhura*, *Pravrajya / Sanyasa*, *Maha Parivartana*.

## 🚀 How to Run Locally

### Prerequisites
- JDK 17+
- Maven 3.8+
- Node.js 18+

### 1. Spring Boot Backend & Frontend
```bash
# Clone the repository
git clone https://github.com/adithiyan-rajaperumal/java-astro.git
cd java-astro

# Run backend (automatically builds and serves static frontend)
mvn clean spring-boot:run
```
Access the application at `http://localhost:8080`.

### 2. Frontend Hot-Reload Development (Vite)
```bash
cd frontend
npm install
npm run dev
```
Access the Vite dev server at `http://localhost:5173`.

### 3. Production Docker Build
```bash
docker build -t drikvedic-app .
docker run -p 8080:8080 drikvedic-app
```

## 📖 Key REST Endpoints & Swagger UI

- **Swagger UI URL**: `http://localhost:8080/swagger-ui.html`
- **Panchangam API**: `POST /api/v1/astrology/panchangam` — Returns full daily Panchangam, Horais, Nalla Neram, Subha Muhurtham window, and caution flags.
- **Horoscope Calculation**: `POST /api/v1/astrology/calculate` — Computes natal birth chart, Doshams, Rajayogas, Ayurdaya, and Ayurvedic Prakriti.
- **Marriage Matching**: `POST /api/v1/astrology/match` — Evaluates 10-Porutham matching score between bride and groom charts.
- **PDF Generation**: `POST /api/v1/astrology/export-pdf` — Generates a downloadable PDF horoscope report.
